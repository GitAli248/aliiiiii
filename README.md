**Welcome** — a fully bootable pixel-art operating system that also happens to be a portfolio.

No React. No Vite. No build step. Just raw `index.html`, boot loader, window manager, and absurd attention to detail.

---

### 📟 THE SYSTEM

-  **Window Manager** — drag, focus, minimize, close. Taskbar + START menu.
-  **Boot Sequence** — CRT-style boot with a spinning loader before the desktop mounts.
-  **Wallpapers** — switch themes on the fly, persisted to `localStorage`.
-  **apps.exe suite** — ABOUT, PROJECTS, README cards, SKILLS potions, EXPERIENCE, SERVICES, WEB, CONTACT, TERMINAL, CODE, and a working Recycle Bin.
-  **Terminal** — a real command palette (`help`, `about`, `open`, `clear`…).
-  **Pixel design system** — chunky bevels, 3px black borders, CRT glow, desktop icons.
