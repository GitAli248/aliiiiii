## ── about.txt

This repository is my **terminal-themed portfolio** — a single-file web experience that blurs the line between a command line and a modern portfolio site. No frameworks. No build step. Just the raw trinity: HTML, CSS, and Vanilla JavaScript.

It's personal, it's opinionated, and it's deliberately over-engineered in the places that matter (the donut rotates at exactly 0.08 radians per tick) and minimal where they don't.

### Features

| Flag | Description |
|---|---|
| `--ascii-donut` | Three.js torus particle system rendering binary 0s and 1s |
| `--typing-anim` | Generative typewriter effects on section headers and commands |
| `--scramble-decode` | Scramble-decrypt text reveals on every paragraph |
| `--crt-effect` | Scanline overlay for that genuine retro-terminal feel |
| `--custom-cursor` | ASCII arrow cursor that follows your every move |
| `--responsive` | Graceful collapse from desktop terminal to mobile view |
| `--contact` | Live contact form powered by EmailJS |
