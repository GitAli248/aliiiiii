### About This Site

This is my **terminal-themed portfolio** — a single-file HTML/CSS/JS experience that blurs the line between a command line and a modern portfolio site. No frameworks, no build step, just the raw trinity.

**Features:** Three.js ASCII donut particle system, typewriter animations, scramble-decrypt text reveals, CRT scanline overlay, custom cursor, and a live contact form powered by EmailJS.

**Stack:** HTML5 · CSS3 · Vanilla JS · Three.js · JetBrains Mono
